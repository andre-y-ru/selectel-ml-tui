# Финальный чек-лист тестирования (релиз 1.0.0)

Прогон на каждой ОС (Ubuntu 22.04/24.04 и macOS 12+). Автоматические проверки
выполняются в CI (GitHub Actions: `ubuntu-latest`, `macos-latest`); ручные —
в терминале.

## Автоматически (CI: `make test lint typecheck`)

- [x] Установка: `python3 -m venv .venv && .venv/bin/pip install -e ".[dev]"`
- [x] CLI entry point: `selectel-ml-tui --version` → 1.0.0
- [x] Первый запуск без токена: подсказка + exit code 1
- [x] Линт: `ruff check src tests`
- [x] Типы: `mypy src` (strict)
- [x] Тесты: `pytest --cov=selectel_ml_tui` (порог 80%)
- [x] Диагностика: `selectel-ml-tui doctor`
